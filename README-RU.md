# LeafView Custom Tauri — сведения о сборке HF3

**Контрольная версия:** `v0.1.2 HF3`, принята пользователем 26 октября 2026 года.

Проект — неофициальная адаптация LeafView для Windows 11 на Tauri 2 + Rust + React + TypeScript + Leaflet. Авторское уведомление оригинального LeafView сохранено в `LICENSE.md`.

## Функциональность

- Нижняя панель не перекрывает изображение постоянно; появляется у нижнего края.
- Название файла и индекс доступны в нативном заголовке Windows.
- Стрелки влево/вправо и PageUp/PageDown переключают изображения без зацикливания.
- Ctrl+O, кнопка «Открыть…», меню и drag-and-drop позволяют открывать файлы.
- Сетка миниатюр, масштабирование, перетаскивание изображения, контекстное меню.
- Esc закрывает окно и при открытых вспомогательных элементах.
- Удаление запрашивает подтверждение и отправляет изображение в Корзину Windows.
- Просмотр изображений сохраняет карту Leaflet между переходами и заранее декодирует замену.

## История исправлений

- **HF2 (Bounds Type Fix + InstallerFix):** корректные `L.LatLngBounds`, поддержка SHA-256 через .NET/certutil, CMD без UTF-8 BOM с CRLF.
- **HF3 (Open Button Fix):** исправлен порядок слоёв стартового экрана в `src/App.scss`; слой `.view.init` не перехватывает клики; добавлен `tests/open-button.test.mjs`.

## Проверено

26.10.2026: пользователь собрал portable EXE на Windows 11: 12/12 JS-тестов, 2/2 Rust unit-теста, TypeScript + Vite, Tauri Release успешно. Подтверждена работа кнопки «Открыть…» и сочетания Ctrl+O. Полный набор ручных сценариев был ранее проверен на HF2; после HF3 только указанные действия проверены повторно.

Сборка portable: `BUILD-PORTABLE-ONLY.cmd`. Сборка с NSIS: `BUILD-WINDOWS.cmd` (для HF3 не проверялась). На другом ПК WebView2 может потребоваться отдельно. Приложение не имеет цифровой подписи.

## Известные ограничения

- Интерфейс русскоязычный и тёмный; светлая тема и меню языков Electron-версии не перенесены.
- Portable EXE не регистрирует ассоциации форматов и не создаёт ярлыки.
- Microsoft SmartScreen может предупреждать о неподписанном файле.
- Оригинальная версия LeafView и эта неофициальная адаптация — разные проекты.

## Разработка

Минимальные регрессионные проверки перед будущими фиксами: `npm test`, `cargo test --manifest-path src-tauri/Cargo.toml`, `npm run tauri -- build --no-bundle`, затем ручной тест EXE. Изменения проводить от контрольной базы HF3. Перепроверять кликабельность кнопки Open, Esc, удаление в корзину, отсутствие мерцания и навигацию на границах списка.

# LeafView Custom Tauri — стабильный выпуск HF7.1

**База разработки: `v0.1.2 HF7.1`.** Windows 11 x64, Tauri 2 + Rust + React + TypeScript + Leaflet. Неофициальная адаптация LeafView; сохранены MIT и оригинальные уведомления об авторстве.

## Функции

- Старт развёрнутым, F11 — полноэкранный режим. Нижняя панель проявляется за 64 пикселя до нижнего края и удерживается до 128 пикселей.
- Имя файла и счётчик изображений в заголовке. Стрелки и PageUp/PageDown переключают изображения без зацикливания.
- Ctrl+O, кнопка открытия, перетаскивание файлов, сетка миниатюр и контекстное меню.
- Масштабирование колесом, перемещение мышью, двойной щелчок для центрирования.
- HF6: между изображениями разных размеров больше нет визуального движения к центру; новое изображение заранее декодируется и размещается относительно постоянного центра.
- HF7: встроенный беззвучный диалог подтверждения удаления. HF7.1: Enter отправляет файл в Корзину; Tab → Enter отменяет; кнопки работают мышью. Esc закрывает приложение (сохранено).
- HF4: обратимая регистрация восьми графических форматов Windows для текущего пользователя; защищённый UserChoice не изменяется.

## Установка

Скачайте архив Portable ZIP из GitHub Releases, распакуйте в постоянную папку и запустите EXE. Запустите `REGISTER-LEAFVIEW.cmd` для добавления в список просмотрщиков Windows; для отмены регистрации — `UNREGISTER-LEAFVIEW.cmd`. Выбор программы по умолчанию делается в Windows. Файлы неподписаны; SmartScreen может предупредить. На некоторых ПК нужен WebView2 Runtime.

## Разработка

Для последующих патчей использовать только контрольную HF7.1; перед фиксацией выполнять `npm test`, `npm run build`, `npm run tauri -- build --no-bundle` и ручное тестирование. Сборка установщика NSIS отдельно не проверялась. Не менять корректную логику навигации, центрирования и безопасного удаления.

# LeafView Custom Tauri — сведения о сборке HF5

**Контрольная версия:** `v0.1.2 HF5`, зафиксирована после подтверждения работы улучшений HF5.

Проект — неофициальная адаптация LeafView для Windows 11 на Tauri 2 + Rust + React + TypeScript + Leaflet. Авторское уведомление оригинального LeafView сохранено в `LICENSE.md`.

## Функциональность

- Нижняя панель не перекрывает изображение постоянно; появляется у нижнего края.
- Название файла и индекс доступны в нативном заголовке Windows.
- Стрелки влево/вправо и PageUp/PageDown переключают изображения без зацикливания.
- Ctrl+O, кнопка «Открыть…», меню и drag-and-drop позволяют открывать файлы.
- Сетка миниатюр, масштабирование, перетаскивание изображения, контекстное меню.
- Esc закрывает окно и при открытых вспомогательных элементах.
- Удаление запрашивает подтверждение и отправляет изображение в Корзину Windows.
- Просмотр изображений сохраняет карту Leaflet между переходами и заранее декодирует замену.

## Известные ограничения

- Интерфейс русскоязычный и тёмный; светлая тема и меню языков Electron-версии не перенесены.
- Portable EXE самостоятельно не назначается просмотрщиком по умолчанию: запуск `REGISTER-LEAFVIEW.cmd` регистрирует приложение для текущего пользователя, а окончательный выбор остаётся в настройках Windows; ярлыки автоматически не создаются.
- Microsoft SmartScreen может предупреждать о неподписанном файле.
- Оригинальная версия LeafView и эта неофициальная адаптация — разные проекты.

## Разработка

Минимальные регрессионные проверки перед будущими фиксами: `npm test`, `cargo test --manifest-path src-tauri/Cargo.toml`, `npm run tauri -- build --no-bundle`, затем ручной тест EXE. Изменения проводить от контрольной базы HF5. Перепроверять кликабельность кнопки Open, Esc, удаление в корзину, отсутствие мерцания и навигацию на границах списка.

## Дополнения HF4 / HF5

- HF4: регистрация просмотрщика через `REGISTER-LEAFVIEW.cmd` для 8 форматов, отмена через `UNREGISTER-LEAFVIEW.cmd`; системное назначение по умолчанию выбирает пользователь.
- HF5: зона появления панели — 64 пикселя от нижнего края, удержание — 128; анимации Leaflet при перелистывании отключены; окно запускается развёрнутым с сохранением нативного заголовка и клавиши `F11`.
- Результаты проверки HF5: 19/19 JS-тестов, TypeScript + Vite, релизная сборка Tauri Windows и все 4 ручных сценария пройдены.
- Новые изменения начинать на основе HF5, не меняя зафиксированный релиз HF3.

# LeafView Custom — Tauri Edition

**Стабильная версия: v0.1.2 HF7.1 (Windows 11, x64).**

Неофициальная адаптация [LeafView](https://github.com/sprout2000/leafview) на **Tauri 2 + Rust + React + TypeScript + Leaflet**, без Electron Runtime. Лицензия MIT и упоминание первоначального автора sprout2000 сохранены в [LICENSE.md](LICENSE.md).

## Возможности

- Окно стартует развёрнутым (не F11); F11 включает и выключает настоящий полноэкранный режим.
- Нижняя панель появляется за 64 пикселя до нижнего края и удерживается до 128 пикселей.
- Перелистывание изображений разных размеров без плавных анимаций и движения к центру (HF5 + HF6).
- Подгонка по центру, масштабирование колесом, перетаскивание, двойной щелчок для сброса масштаба.
- Название файла и позиция в заголовке; стрелки переключают изображения без зацикливания.
- Ctrl+O, кнопка открытия, перетаскивание файлов, сетка миниатюр, контекстное меню.
- Подтверждаемое удаление **без звукового предупреждения Windows** (HF7). Enter — «В корзину», Tab → Enter — «Отмена» (HF7.1). Файлы перемещаются в Корзину Windows; Esc по-прежнему закрывает приложение.
- Регистрация приложения для BMP, GIF, ICO, JPEG, JPG, PNG, SVG и WebP (HF4) под текущей учётной записью, без изменения защищённого Windows UserChoice.

## Скачать и запустить

Откройте [релиз v0.1.2-hf7.1](https://github.com/TraurigerEngel/LeafView-Custom-Tauri/releases/tag/v0.1.2-hf7.1). Скачайте Portable ZIP, распакуйте в постоянную папку и запустите `LeafView Custom Tauri.exe`. Для регистрации форматов используйте `REGISTER-LEAFVIEW.cmd`; для отмены — `UNREGISTER-LEAFVIEW.cmd`. Выбор программы по умолчанию производится в настройках Windows 11. Подробнее: [FILE-ASSOCIATIONS-RU.md](FILE-ASSOCIATIONS-RU.md).

Это Portable EXE без цифровой подписи. В отдельных Windows может потребоваться Microsoft Edge WebView2 Runtime. При перемещении папки после регистрации повторите `REGISTER-LEAFVIEW.cmd`, поскольку ассоциации зависят от абсолютного пути.

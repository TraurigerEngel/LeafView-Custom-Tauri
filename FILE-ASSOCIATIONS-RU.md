# LeafView — регистрация в Windows 11 (включено в HF5)

**Регистрация не делает приложение автоматически выбранным по умолчанию.** Windows 11 защищает пользовательский выбор. После регистрации нужно один раз выбрать LeafView в системном интерфейсе Windows.

## Регистрация

1. Для исходников соберите EXE в `src-tauri\target\release\LeafView Custom Tauri.exe`. Для Portable-архива оставьте EXE рядом с `REGISTER-LEAFVIEW.cmd`.
2. Запустите двойным щелчком `REGISTER-LEAFVIEW.cmd` из корня проекта.
3. Откроются **Параметры → Приложения → Приложения по умолчанию → LeafView Custom Tauri**. Выберите приложение для нужных расширений (либо доступную кнопку назначения по умолчанию).

Зарегистрированы `.bmp`, `.gif`, `.ico`, `.jpeg`, `.jpg`, `.png`, `.svg`, `.webp` (точно как в `tauri.conf.json`). Скрипт меняет только пользовательские записи `HKCU`, не требует прав администратора и не изменяет защищённый `UserChoice`.

**Не перемещайте и не переименовывайте EXE после регистрации.** Если путь изменился, повторно запустите `REGISTER-LEAFVIEW.cmd` из актуальной папки проекта (или поменяйте выбранное приложение в Windows).

## Отмена

Запустите `UNREGISTER-LEAFVIEW.cmd`. Удаляются только созданные скриптом записи LeafView в `HKCU`. Предыдущие приложения по умолчанию **не восстанавливаются автоматически**, поскольку Windows хранит выбор отдельно. Выберите другой просмотрщик в системных настройках, если ранее назначали LeafView.

## Диагностика

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\FILE-ASSOCIATIONS.ps1 -Action Status
```

Необходим работающий EXE, но повторная сборка после добавления этих скриптов **не требуется**. Скрипт поддерживает Windows PowerShell 5.1; `Get-FileHash` не используется.

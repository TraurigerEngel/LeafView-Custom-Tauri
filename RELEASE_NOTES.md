# LeafView Custom Tauri v0.1.2 HF3

**Первая закреплённая стабильная контрольная версия** неофициальной Tauri-адаптации LeafView для Windows 11 (x64).

## Главное

- Лёгкий интерфейс на Tauri 2 / Rust / React / Leaflet без Electron runtime.
- Скрывaемая нижняя панель, информация о файле в заголовке Windows.
- Масштабирование, миниатюры, drag-and-drop, навигация без зацикливания.
- Подтверждение удаления и перемещение изображения в Корзину.
- Сохранение Leaflet между переключениями и предварительная декодировка.
- **HF2:** исправление типа `LatLngBounds` при сборке и совместимости скриптов.
- **HF3:** исправлена кнопка «Открыть…» в пустом окне; `Ctrl+O` также проверено.

## Подтверждённые проверки

- JS: **12/12 PASS**; Rust: **2/2 PASS**.
- TypeScript / Vite / Tauri Windows Release: **сборка прошла**.
- Пользователь подтвердил работу кнопки «Открыть…» и `Ctrl+O` на Windows 11.
- Остальные 8 базовых сценариев проходились на HF2; это не повторная полная регрессия HF3.

## Установка

Скачать портативный архив `LeafView_Custom_Tauri_v0.1.2_HF3_Windows_x64_Portable.zip`, распаковать в собственную папку и запустить `LeafView Custom Tauri.exe`. Требуется Windows 11 x64 и WebView2 Runtime. EXE не подписан кодовой подписью; Windows SmartScreen может показать предупреждение.

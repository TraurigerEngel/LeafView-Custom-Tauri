# LeafView Custom Tauri v0.1.2 HF7.1

**Стабильный выпуск Windows 11 x64** с ранее подтверждёнными улучшениями HF4–HF7.1.

## Что нового по сравнению с HF5

### HF6 — No Recenter

- Устранено заметное движение к центру при переключении изображений разных размеров.
- Изображения выравниваются относительно постоянного центра окна без анимаций Leaflet и без видимого перехода камеры.
- Масштабирование, перемещение и двойной щелчок для восстановления центрирования сохранены.

### HF7 — Silent Delete

- Звуковое предупреждение системного диалога Windows устранено: подтверждение удаления теперь встроено в LeafView.
- Удаление по-прежнему требует подтверждения и перемещает файл в Корзину Windows.

### HF7.1 — Enter Delete

- При открытии подтверждения кнопка «В корзину» получает фокус. Enter подтверждает удаление; Tab → Enter выбирает отмену.
- Кнопки доступны для нажатия мышью. Поведение Esc (закрытие приложения) не изменено.

## Сохранено из HF4 / HF5

- Обратимая регистрация приложения для восьми расширений Windows 11 без изменения UserChoice.
- Нижняя панель появляется за 64 пикселя от нижнего края и удерживается до 128 пикселей.
- Перелистывание без fade/zoom-slide; запуск в развёрнутом окне; F11 для настоящего полноэкранного режима.
- Проверенные ранее функции открытия, прокрутки, миниатюр, меню, названия окна и удаления в Корзину.

## Установка

Скачайте `LeafView_Custom_Tauri_v0.1.2_HF7.1_Windows_x64_Portable.zip`, распакуйте в постоянную папку и запустите EXE. `REGISTER-LEAFVIEW.cmd` добавляет просмотрщик в список приложений текущего пользователя Windows, `UNREGISTER-LEAFVIEW.cmd` отменяет регистрацию. Назначение по умолчанию выполняется отдельно в Windows 11. Приложение не подписано; WebView2 Runtime может потребоваться отдельно.

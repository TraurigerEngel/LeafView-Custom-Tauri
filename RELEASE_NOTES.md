# LeafView Custom Tauri v0.1.2 HF5

**Стабильный контрольный выпуск для Windows 11 x64**, принятый после автоматической сборки и ручной проверки функций HF5.

## Изменения после HF3

### HF4 — регистрация приложения

- Добавлены `REGISTER-LEAFVIEW.cmd`, `UNREGISTER-LEAFVIEW.cmd` и `scripts/FILE-ASSOCIATIONS.ps1`.
- Регистрация восьми расширений изображений только для текущего пользователя Windows (HKCU), без прав администратора.
- Не выполняется принудительная смена приложения по умолчанию: пользователь назначает LeafView через настройки Windows 11.

### HF5 — улучшения просмотра

- Нижняя панель появляется при приближении указателя к нижнему краю на 64 пикселя, а не 16.
- Панель удерживается до 128 пикселей от нижнего края для удобства.
- Отключены плавные анимации Leaflet при смене изображения.
- Окно запускается развёрнутым, с обычным заголовком Windows; `F11` работает как прежде.

## Проверки

- Исходники релиза дополнительно проверены 20/20 JavaScript-тестами, включая новый тест для регистрации при переносимом размещении EXE; на Windows подтверждены 19 ранее существовавших тестов.

- На ПК Windows 11: 19/19 JavaScript-тестов, TypeScript, Vite Production Build и Tauri Release Build успешны.
- Пользователь подтвердил четыре изменения HF5: нижняя панель, отсутствие анимации, развёрнутое окно и `F11`.
- HF4: успешная регистрация в Windows, 16/16 JS-тестов. Изменение UserChoice не производится.
- Настроенные ассоциации зависят от абсолютного пути к EXE. После переноса приложения регистрацию следует повторить.

## Установка

Скачайте `LeafView_Custom_Tauri_v0.1.2_HF5_Windows_x64_Portable.zip`, распакуйте в постоянную папку, затем запустите `LeafView Custom Tauri.exe`. Если хотите зарегистрировать просмотрщик, запустите `REGISTER-LEAFVIEW.cmd` в папке приложения. Windows 11 может потребовать Microsoft Edge WebView2 Runtime. Приложение не подписано цифровой подписью.
